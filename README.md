# Camera Filter

| Folder | Contents |
|---|---|
| `lens/` | Simulating a photo taken through an out-of-focus mask in front of the lens, C = A · blur(B) (`calculate_C.py`), and recovering the mask B from the scene A and the photo C (`calculate_B.py`) |
| `code/` | Learning a photographer's black-and-white edits: given a grayscale original photo, predict the photographer's edited version (brightness, contrast and local tone adjustments) |

## Learning the photographer's edits (`code/`)

**Code only — no data.** The photos are private, so `data/` and the model weights are not tracked, and notebook outputs (which would embed photos) are stripped when committing (git filter, see `.gitattributes`).

### Notebooks

| Notebook | What it does |
|---|---|
| `data_cleaning.ipynb` | Pairs each original with its edit by photo ID, finds where the (often cropped or straightened) edit sits in the original with SIFT + RANSAC, rejects pairs that cannot be aligned, and writes aligned 720×480 grayscale pairs |
| `data_separation.ipynb` | Per-pair 80/20 train/test split (seed 42) |
| `model_learn_correlations.ipynb` | Evaluation metrics: relative MAE, PSNR, SSIM |
| `model.ipynb` | Residual U-Net (7.77M parameters, 144×96 grayscale input, L1 loss) with early stopping on a validation split |
| `predict.ipynb` | Applies the saved model, computes per-image metrics (`test_metrics.csv`), shows the best and worst cases |

Run them in that order. Expected data layout (not in the repository):

```
data/raw_data/original/   original photos
data/raw_data/edited/     the photographer's edited exports
```

Everything else under `data/` is generated by the notebooks.

Requirements: Python 3.7+, numpy, Pillow, OpenCV with SIFT (`opencv-python` ≥ 4.4 or `opencv-contrib-python`), scikit-image, PyTorch, matplotlib, Jupyter.

### Results so far

Model v1 was trained on the first batch of 309 pairs (223 train / 24 validation) and evaluated on the 62 held-out test pairs at 144×96:

| | relMAE ↓ | PSNR (dB) ↑ | SSIM ↑ |
|---|---|---|---|
| No edit (original vs. edited) | 0.2009 | 20.27 | 0.8715 |
| Model v1 | 0.1884 | 21.42 | 0.8784 |

The model beats the no-edit baseline on 39 of 62 test images. It mostly learned a global brightening and does worst on photos the photographer darkened. Per-image numbers are in `code/test_metrics.csv`.

**Next:** the earlier cleaning step kept only 396 pairs because it discarded every cropped edit; the rewritten `data_cleaning.ipynb` aligns cropped edits instead. Next steps are re-running it on all raw exports, re-splitting, and retraining.
